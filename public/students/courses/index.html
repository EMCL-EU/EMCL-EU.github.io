Below you can find a list of the courses offered per term.
For a more detailed description of the courses, please have a look at this document.

1st term: University of Eastern Finland (Joensuu, Finland)

  • Language and Languages - A Course on General Linguistics (5 ECTS, module 1)
  • Language and Languages - Linguistic Reading Group (3 ECTS, module 1)
  • Empirical Research Methods in Linguistics (5 ECTS, module 2)
  • Introduction to Python Programming for Linguistic Research (3 ECTS, module 2)
  • Introduction to Phonetics and the Praat Tool (2 ECTS, module 2)
  • Statistics and Data Visualisation for Linguistics (5 ECTS, module 2)
  • Introduction to Praat Script Programming for Clinical Linguistic Research (2 ECTS, module 2)
  • Introduction to Developmental and Acquired Speech and Language Problems (taught by RUG, 5 ECTS, module 4)

2nd term: University of Ghent (Belgium)

  • Statistics and Research Methods applied to the development and validation of language research tools (7 ECTS, module 2)
  • Bilingualism (4 ECTS, module 3)
  • Reading Acquisition and Dyslexia (4 ECTS, module 4)
  • Computational Models in Psycholinguistics (4 ECTS, module 3)
  • Advances in Psycholinguistics (3 ECTS, module 3)
  • Eye-tracking in Language Research (3 ECTS, module 5)
  • Internship Preparation (5 ECTS, module 6)

3rd term: University of Groningen (the Netherlands)

  • Advanced course in Developmental and Acquired Speech and Language Problems (5 ECTS, module 4)
  • Apps and Games in Clinical Linguistics (5 ECTS, module 5)
  • Language Testing during Awake Brain Surgery (5 ECTS, module 4)
  • Neuroimaging and Language (5 ECTS, module 5)
  • Internship (10 ECTS, module 6)

4th term: Various locations

  • Thesis (30 ECTS, module 7)
